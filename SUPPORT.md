# Support

Logseq Matryca Parser is a local-first Python parser and graph library. Support
is focused on the documented package, CLI, parser behavior, graph APIs, and
safe filesystem workflows.

## Where to ask

- **Bug reports:** open a public [GitHub issue](https://github.com/MarcoPorcellato/logseq-matryca-parser/issues)
  with a minimal reproduction.
- **Feature proposals:** open an issue after checking the existing roadmap and
  good-first issue catalogue.
- **Security vulnerabilities:** follow [`SECURITY.md`](SECURITY.md). Do not
  disclose vulnerabilities in a public issue.
- **Contribution questions:** read [`CONTRIBUTING.md`](CONTRIBUTING.md) and
  include the relevant issue or pull request when asking for help.

## Include in a useful report

Please provide:

- package version and Python version;
- operating system and installation method;
- the smallest safe Markdown fixture or a redacted reproduction;
- the command or Python code that reproduces the behavior;
- expected and observed results;
- a traceback or diagnostic output when available.

Never attach a private vault, credentials, tokens, or sensitive personal data.
Redact file contents and paths when they are not needed to reproduce the issue.

## Support boundary

The project does not promise custom vault migrations, hosted infrastructure,
model-provider support, or compatibility with undocumented private APIs. Optional
AI and visualization integrations remain separately documented and may have
their own dependency or upstream support requirements.

Security response expectations are defined in [`SECURITY.md`](SECURITY.md).
General issue response time depends on maintainer availability; opening an issue
does not guarantee a feature or a fixed release date.

## Current release policy

Security support follows the latest-release policy in [`SECURITY.md`](SECURITY.md).
For installation, API stability, recipes, and release history, start from the
[documentation portal](docs/README.md).
