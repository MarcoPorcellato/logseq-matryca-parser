# Public roadmap for 2026–2027

This is the canonical public navigation view for the GitHub, assurance,
interoperability, and AAIF-readiness programme.
The detailed evidence, exclusions, and historical anchors remain in the
[readiness study](REPOSITORY_GOVERNANCE_AAIF_STUDY_2026-08-19.md). It is a
roadmap, not a release promise or an AAIF submission claim.

## Status vocabulary

| Status | Meaning |
|---|---|
| Completed locally | Source changes and local checks are complete; publication is recorded separately |
| In progress | An owner is actively working within a defined scope |
| Waiting for evidence | Requires current external, release, security, or adoption evidence |
| Research only | A bounded study is authorized, but no product implementation is committed |
| Deferred | Intentionally postponed until a dependency or user need exists |

## What this roadmap does not promise

- a date for an MCP or A2A implementation;
- a persistent cache, process-pool default, Logseq DB adapter, DuckDB export,
  bidirectional Obsidian sync, standalone binary, GUI, or editor extension
  before its evidence and adoption gates pass;
- a security, release, or AAIF claim without independent evidence;
- a second maintainer before a qualified person accepts that role;
- a release schedule or feature commitment merely because an item appears here.
